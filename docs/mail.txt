A couple of things to remember to play:

🔍 Langfuse Tracking - MANDATORY
Langfuse is required for tracking and validation purposes. Every submission must include a valid Langfuse Session ID. Follow the detailed guide to set it up: API Guidelines. Make sure there are no spaces when you insert your session id and use the following host: https://challenges.reply.com/langfuse.

🔓 Dataset Unlocking Mechanism
At challenge start: Datasets 1-3 are available
After submitting evaluation solutions for datasets 1-3: Datasets 4-5 unlock automatically
 

📊 How Submissions Work: Training vs. Evaluation

Training Datasets (1-5):
Submit as many times as you want (while keeping track of your tokens - read below)
Test and refine your agentic system
Scores are estimates only and won't count toward your final ranking
Use these to perfect your approach!
Evaluation Datasets (1-5):

ONE submission only per dataset
Must include: output file + source code (.zip)
Your final score is based ONLY on evaluation submissions
Make sure to test thoroughly with training datasets first!
⚠️ Key Point: Always test your solution on the training dataset before submitting to the evaluation dataset. You only get one chance for evaluation!

 

🔑 API Keys & Token Budget

Your token allocation is divided into two stages:

$40 for datasets 1-3 (available at challenge start)
$120 for datasets 4-5 (unlocked ONLY after you submit final evaluation solutions for datasets 1-3)
On your challenge page you’ll see a dedicated widget showing your left tokens
